name: research-topic
description: Use when choosing, vetting, or comparing research directions or topics, or checking whether an idea has already been done, before writing a hypothesis card.
---

Read `docs/guides/RESEARCH-TOPIC.md` and apply it.

- Use **Part 1** to critique the idea: point out where it starts from a method instead of a problem, skips the cheap oracle test, or targets last year's discourse.
- Then run **Part 2**. Never cite a paper whose ID you haven't fetched. If a claim is already done, say so plainly and suggest the narrower gap that's left.
- Give the guide's **Output** block, then hand off to `hypothesis-card`.
